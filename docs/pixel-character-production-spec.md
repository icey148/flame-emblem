# Flame Emblem 像素人物制作规范

本规范用于正式原创人物素材生产。目标是保持经典复古战棋 RPG 的低分辨率、强职业辨识和短促战斗节奏，同时不复制任何既有商业游戏的具体角色、动画帧、UI 或美术资源。

## 1. 总体原则

- 地图人物和战斗人物使用独立素材，不把同一张图强行缩放复用。
- 所有像素素材使用透明背景 PNG。
- Godot 使用最近邻过滤，不允许线性平滑。
- 人物轮廓优先于细节：低分辨率下必须先能看出职业，再看出角色个人配色。
- 同职业可以共享骨架，但主角/重要角色允许在发型、披风、肩甲、帽子、法书、武器长度等位置增加个人差异。
- 原创人物只借鉴“复古战棋的表现语言”，不临摹任何现成角色或逐帧动画。

## 2. 地图人物规格

### 2.1 画布

- 推荐源画布：`32 × 32 px`
- 人物主体推荐高度：`22–28 px`
- 脚底基准线：Y = 28
- 左右各保留至少 2 px 透明边距
- 武器可以超过人物主体，但尽量不要超过画布边缘

### 2.2 必需状态

每个可上场职业至少提供：

- `idle_down`: 2 帧
- `idle_up`: 2 帧
- `idle_left`: 2 帧
- `idle_right`: 2 帧
- `walk_down`: 3 帧
- `walk_up`: 3 帧
- `walk_left`: 3 帧
- `walk_right`: 3 帧

文件示例：

```text
assets/characters/adrian/map/
├── idle_down_0.png
├── idle_down_1.png
├── idle_up_0.png
├── idle_up_1.png
├── idle_left_0.png
├── idle_left_1.png
├── idle_right_0.png
├── idle_right_1.png
├── walk_down_0.png
├── walk_down_1.png
├── walk_down_2.png
├── walk_up_0.png
├── walk_up_1.png
├── walk_up_2.png
├── walk_left_0.png
├── walk_left_1.png
├── walk_left_2.png
├── walk_right_0.png
├── walk_right_1.png
└── walk_right_2.png
```

### 2.3 地图动作节奏

- Idle：约 2–3 FPS
- Walk：约 8–10 FPS
- 单格移动时间：当前代码基线约 0.14 秒
- 行走帧要表现脚步交替，不要用整个人物上下平移代替真正步态

## 3. 战斗人物规格

### 3.1 画布

推荐两种档位：

- 基础：`96 × 96 px`
- 精细：`128 × 128 px`

同一项目内尽量统一一个档位。当前程序层会按控件尺寸最近邻放大。

### 3.2 基准位置

- 人物脚底必须保持在同一水平基线
- 朝右人物按正常方向绘制
- 右侧敌人由程序水平镜像，因此不要求重复绘制左右两套战斗素材
- 武器攻击帧可以短暂超过人物常规包围盒，但不要裁切关键武器尖端

### 3.3 必需状态与推荐帧数

| 状态 | 推荐帧数 | 用途 |
| --- | ---: | --- |
| `idle` | 2–4 | 战斗待机 |
| `attack` | 4–6 | 物理攻击 / 弓攻击 |
| `cast` | 4–6 | 魔法施放 |
| `hit` | 2–3 | 命中受击 |
| `dodge` | 2–4 | 未命中闪避 |
| `defeat` | 4–6 | 击倒 / 退场 |

文件示例：

```text
assets/characters/adrian/battle/
├── idle_0.png
├── idle_1.png
├── attack_0.png
├── attack_1.png
├── attack_2.png
├── attack_3.png
├── hit_0.png
├── hit_1.png
├── dodge_0.png
├── dodge_1.png
├── defeat_0.png
├── defeat_1.png
├── defeat_2.png
└── defeat_3.png
```

法师额外使用：

```text

```

## 4. 三种基础身体模板

当前程序回退人物已经实现三种身体模板，正式素材建议沿用同样的职业语言。

### Light / 轻装

适合：剑士、弓手、盗贼、佣兵等。

视觉重点：

- 窄肩
- 短上衣或轻甲
- 双腿明显分离
- 攻击前冲距离可以较大
- 闪避动作明显

当前角色：

- Adrian
- Celine
- 普通 Raider

### Armored / 重甲

适合：枪兵、守卫、重骑、Boss 护卫等。

视觉重点：

- 宽肩甲
- 厚胸甲
- 腿甲和靴子更大
- 攻击动作更短、更有重量感
- 闪避幅度小

当前角色：

- Rowan
- Guard
- Bridge Captain

### Robed / 长袍

适合：法师、祭司、术士等。

视觉重点：

- 上身较窄
- 宽袖
- 腰部以下有展开袍摆
- 脚部只少量露出
- Cast 时袍摆/袖口可以出现轻微魔力亮边

当前角色：

- Mira

## 5. 武器职业轮廓

### Sword

- 地图：短而明显的亮刃
- 战斗：攻击帧突出横斩或斜斩
- 武器长度不要和枪接近

### Spear

- 地图：长直轮廓
- 战斗：攻击帧以突刺为主
- 枪尖必须在低分辨率下仍可读

### Bow

- 地图：弧形分段轮廓
- 战斗：攻击帧必须表现拉弓 → 放箭
- 箭矢飞行特效由表现层扩展，不需要全部画进人物帧

### Tome

- 地图：法书靠近身体，配一个小型魔力像素
- 战斗：人物负责 Cast 动作，真正魔法弹/火焰/雷击由特效层绘制

## 6. 调色建议

每个角色建议控制在约 8–16 个主要颜色内：

- 轮廓深色：1–2 色
- 肤色：2–3 色
- 发色：2–3 色
- 服装主色：2–3 色
- 强调色：1–2 色
- 金属/武器：2–3 色

不要依赖大量渐变。职业识别主要来自轮廓、明暗块和武器，不来自高色数。

## 7. 当前四名玩家角色的原创方向

### Adrian — Vanguard / Light / Sword

- 棕色短发
- 深蓝轻甲
- 暖金饰边
- 短披风
- 轮廓重点：剑士前倾姿态和披风后摆

### Celine — Scout / Light / Bow

- 暖棕橙发色
- 绿色轻装
- 米金色饰边
- 无披风
- 轮廓重点：弓背在身体外侧，身体比 Adrian 更轻巧

### Rowan — Soldier / Armored / Spear

- 深发色
- 灰蓝重甲
- 暗红强调色
- 宽肩甲
- 轮廓重点：枪长、肩宽、腿甲厚

### Mira — Mage / Robed / Tome

- 紫发
- 蓝紫长袍
- 紫红魔力强调色
- 短披肩/披风
- 轮廓重点：宽袖、袍摆、法书和施法光点

## 8. 导入检查清单

每一套新素材进入仓库前检查：

1. 文件名是否从 `_0` 连续编号。
2. 所有帧画布尺寸是否完全一致。
3. 脚底基准线是否一致。
4. 是否为透明背景 PNG。
5. 是否没有线性平滑产生的半透明边缘。
6. 左右方向是否与命名一致。
7. 战斗人物朝右版本是否正确；右侧敌军由代码镜像。
8. 是否为原创素材，没有复制现有商业游戏具体像素帧。

## 9. 程序回退优先级

当前运行时按以下顺序查找人物素材：

1. 人物实例 ID，例如 `adrian`
2. 职业 ID，例如 `mage`
3. 阵营默认目录 `player_default` / `enemy_default`
4. 如果没有正式 PNG，则使用代码中的原创程序像素职业模板

因此可以先逐个替换重要角色，不需要一次画完所有敌军。
