# 我方角色像素美术生产表

本文档固定 Adrian、Celine、Rowan、Mira 四名我方角色的正式原创像素美术规格。

目标是获得更接近古典日式战棋幻想作品的修长人物比例、清晰职业轮廓和克制配色，同时保持角色造型、像素帧和细节为本项目原创内容，不逐帧复制任何既有商业游戏素材。

---

## 1. 全角色统一技术规格

### 1.1 地图人物

- 逻辑画布：`32 × 32 px`
- PNG：透明背景
- 过滤：Nearest / 最近邻
- 实际人物高度建议：`22 ~ 26 px`
- 脚底基准线：`y = 28`
- 武器可以超出主体宽度，但不应越过 32×32 画布
- 左右方向分别出图，不依赖运行时镜像
- 头身比例目标：约 `1 : 3.2 ~ 1 : 3.8`
- 禁止大头 Q 版比例

地图每名角色共需要 **20 帧**：

| 状态 | 方向 | 帧数 | 文件 |
| --- | --- | ---: | --- |
| Idle | Down | 2 | `idle_down_0.png` ~ `idle_down_1.png` |
| Idle | Up | 2 | `idle_up_0.png` ~ `idle_up_1.png` |
| Idle | Left | 2 | `idle_left_0.png` ~ `idle_left_1.png` |
| Idle | Right | 2 | `idle_right_0.png` ~ `idle_right_1.png` |
| Walk | Down | 3 | `walk_down_0.png` ~ `walk_down_2.png` |
| Walk | Up | 3 | `walk_up_0.png` ~ `walk_up_2.png` |
| Walk | Left | 3 | `walk_left_0.png` ~ `walk_left_2.png` |
| Walk | Right | 3 | `walk_right_0.png` ~ `walk_right_2.png` |

#### Idle 两帧动作原则

- `idle_*_0`：标准站姿，身体重心居中。
- `idle_*_1`：肩/胸只移动 1 像素；披风、头发、袍摆允许变化 1 像素。
- 脚底基准线保持不变，不能让人物看起来上下漂浮。

#### Walk 三帧动作原则

- `walk_*_0`：左脚/前脚迈出，重心偏向支撑腿。
- `walk_*_1`：双脚交汇，身体高度回到中位。
- `walk_*_2`：右脚/后脚迈出，与 0 帧形成对称节奏。
- 身体最多上下变化 1 像素，重点表现腿和重心，而不是整个人上下弹跳。

## 1.2 独立战斗人物

- 逻辑画布：`96 × 96 px`
- 可接受第二规格：`128 × 128 px`，但同一角色整套必须统一
- PNG：透明背景
- 脚底基准线：96px 画布建议 `y = 84`
- 人物实际高度：约 `64 ~ 78 px`
- 默认朝向：面向右侧
- 敌方站位由游戏运行时水平镜像，不需要重复画左右两套战斗素材

通用战斗帧最低要求：

| 状态 | 推荐帧数 | 文件 |
| --- | ---: | --- |
| Idle | 2 | `idle_0.png` ~ `idle_1.png` |
| Attack | 4 | `attack_0.png` ~ `attack_3.png` |
| Hit | 3 | `hit_0.png` ~ `hit_2.png` |
| Dodge | 3 | `dodge_0.png` ~ `dodge_2.png` |
| Defeat | 4 | `defeat_0.png` ~ `defeat_3.png` |
| Cast | 5（法师） | `cast_0.png` ~ `cast_4.png` |

#### Idle

- `idle_0`：标准战斗站姿。
- `idle_1`：胸口/肩线轻微变化 1 像素；披风、头发或袍摆可以有 1~2 像素变化。
- 双脚不离地。

#### Hit

- `hit_0`：接触前一刻。
- `hit_1`：上半身后仰/护甲震动最大。
- `hit_2`：回弹但仍未完全恢复站姿。

#### Dodge

- `dodge_0`：察觉攻击，重心偏移。
- `dodge_1`：侧身或后撤幅度最大。
- `dodge_2`：开始回位。

#### Defeat

- `defeat_0`：失去平衡。
- `defeat_1`：膝盖或上身明显下沉。
- `defeat_2`：主要轮廓倒向地面。
- `defeat_3`：最终倒地/跪倒姿态。

---

## 1.3 头像

- 推荐画布：`64 × 64 px`
- 可选高规格：`96 × 96 px`
- PNG：透明背景
- 构图：头部 + 肩部 + 少量胸口/披风/护甲
- 头顶保留 3~5 px 安全边距
- 不用写实皮肤渐变；使用有限色阶
- 地图人物、头像、战斗人物必须共享同一发色、服装主色和职业识别元素

文件固定为：

```text
assets/characters/<id>/portrait.png
```

# 2. Adrian — 轻装剑士

## 2.1 核心识别

- 体型：Light
- 武器：Sword
- 气质：正统、果断、年轻、前冲型
- 轮廓关键词：短披风、轻甲、窄肩、单手剑、棕色短发

## 2.2 配色

| 部位 | 建议色 |
| --- | --- |
| 头发主色 | `#6C4B34` |
| 头发阴影 | `#493124` |
| 服装主色 | `#445A7A` |
| 服装阴影 | `#2F3E57` |
| 披风蓝 | `#526E94` |
| 米白内衬 | `#D7D1BF` |
| 皮革 | `#5A3D2C` |
| 黄铜 | `#B39455` |
| 金属高光 | `#C7C9C2` |

## 2.3 地图轮廓

- 头部不超过主体总高约 28%。
- 右/左视图中鼻面只用 1~2 px 提示，不做大脸。
- 短披风落到腰后，不超过膝盖。
- 剑鞘/剑刃在侧视中必须成为独立轮廓，不贴死在身体上。
- Down 方向剑柄可以露出肩后或腰侧 2~3 px。
- Up 方向披风面积略大，脸部细节减少。

## 2.4 地图 Walk 每帧

- `walk_*_0`：前脚迈出 1~2 px；剑和披风稍向后。
- `walk_*_1`：双脚靠拢；披风落回中心。
- `walk_*_2`：另一只脚迈出；剑柄位置略有反向摆动。

## 2.5 战斗 Attack 四帧

- `attack_0`：重心后移，剑靠近腰侧，准备发力。
- `attack_1`：前脚迈出，上身前倾，剑开始离鞘/抬起。
- `attack_2`：前冲最大，剑刃穿过身体前方，形成最清晰攻击轮廓。
- `attack_3`：挥砍结束，剑位于身体前下方，准备回位。

## 2.6 Dodge

不要画成整个人平移。重点是：

- 肩线转开；
- 胸口侧身；
- 后脚撤半步；
- 披风反向拖出 2~3 px。

# 3. Celine — 轻装弓手

## 3.1 核心识别

- 体型：Light
- 武器：Bow
- 气质：安静、专注、灵巧
- 轮廓关键词：细长、长弓、箭袋、墨绿、棕橙中短发

## 3.2 配色

| 部位 | 建议色 |
| --- | --- |
| 头发主色 | `#A66E42` |
| 头发阴影 | `#70482D` |
| 服装主色 | `#4E6A4B` |
| 服装阴影 | `#344A36` |
| 浅绿灰披肩 | `#788878` |
| 米白 | `#D9D3BE` |
| 皮革 | `#5A3C2A` |
| 弓木色 | `#7B5434` |
| 金属扣件 | `#A99468` |

## 3.3 地图轮廓

- 肩宽略小于 Adrian。
- 侧视身体有轻微转体，不完全正侧面。
- 长弓必须形成明显弧线；即使缩到 32×32 也不能像一根棍。
- 箭袋放在背后偏外侧，至少露出 2~3 支箭尾的像素提示。
- 下摆短，腿部轮廓清楚，体现移动灵活。

## 3.4 地图 Walk 每帧

- `walk_*_0`：弓略向后，箭袋箭尾向反方向摆 1 px。
- `walk_*_1`：弓接近竖直/稳定位置。
- `walk_*_2`：弓略向前，箭袋回摆。

## 3.5 战斗 Attack 四帧

- `attack_0`：弓下位，身体侧向目标。
- `attack_1`：抬弓，前臂伸直。
- `attack_2`：拉弦到最大，后肘明显后移；这是停顿感最强的一帧。
- `attack_3`：松弦，弓臂向前弹，后手回到脸侧或胸侧。

## 3.6 Dodge

- 重心先压低，再侧身后撤。
- 弓必须跟随身体，不要留在原位置。
- 箭袋可以延迟 1 帧回摆，增加轻装角色的惯性感。

# 4. Rowan — 重甲枪兵

## 4.1 核心识别

- 体型：Armored
- 武器：Spear
- 气质：可靠、稳、沉重
- 轮廓关键词：宽肩甲、厚胸甲、腿甲、大靴、长枪

## 4.2 配色

| 部位 | 建议色 |
| --- | --- |
| 头发 | `#3D342F` |
| 铠甲主色 | `#6A7482` |
| 铠甲阴影 | `#444D5A` |
| 铠甲高光 | `#9098A1` |
| 皮革 | `#51382A` |
| 暗红识别色 | `#8D4B43` |
| 黄铜 | `#A88A55` |
| 枪尖高光 | `#C9CBC6` |

## 4.3 地图轮廓

- 肩宽必须明显大于 Adrian/Celine。
- 胸甲至少占躯干宽度的 60~70%。
- 腿甲分块清楚，不要画成长裤。
- 靴子比轻装职业多 1~2 px 宽度。
- 长枪必须贯穿角色高度方向形成强职业识别。

## 4.4 地图 Walk 每帧

- 上半身位移尽量少。
- `walk_*_0`：前脚迈出，但肩甲保持稳定。
- `walk_*_1`：双脚交汇，枪杆最接近竖直。
- `walk_*_2`：另一脚迈出，枪尾/枪尖轻微反向摆动。
- 不要做明显上下弹跳，重甲感来自“重心低、上身稳”。

## 4.5 战斗 Attack 四帧

- `attack_0`：双手握枪，枪尖略抬，身体压低。
- `attack_1`：后脚蹬地，枪杆拉到身体侧后方。
- `attack_2`：直线突刺最大，枪杆几乎水平，身体只前进少量。
- `attack_3`：枪尖回收一部分，保持防守重心。

## 4.6 Hit / Dodge

- Hit：胸甲和肩甲震动比身体位移更明显。
- Dodge：不做大幅跳开，只做偏肩、撤脚、枪杆护身。
- 这能和 Adrian/Celine 的灵活闪避形成鲜明差异。

# 5. Mira — 长袍法师

## 5.1 核心识别

- 体型：Robed
- 武器：Tome
- 气质：冷静、神秘、柔和但危险
- 轮廓关键词：长袍、宽袖、展开袍摆、紫色中长发、法书/法器

## 5.2 配色

| 部位 | 建议色 |
| --- | --- |
| 头发主色 | `#76517B` |
| 头发阴影 | `#513657` |
| 长袍主色 | `#514B79` |
| 长袍阴影 | `#353252` |
| 袖口/内衬 | `#CBC5D2` |
| 强调紫 | `#A16BB2` |
| 淡银金属 | `#BFC3C8` |
| 法术浅蓝紫 | `#9DA9D9` |
| 法术暖白 | `#E4DCC6` |

## 5.3 地图轮廓

- 腿部不强调分离，主要由袍摆表达下半身。
- 袍摆宽度略大于肩宽，形成倒梯形轮廓。
- 袖口在左右方向至少突出主体 1~2 px。
- 头发比其他三人更长，侧发/后发必须可识别。
- 法书贴近胸前或身体侧前方；不要像盾牌一样过大。

## 5.4 地图 Walk 每帧

- `walk_*_0`：袍摆左侧展开 1 px，右侧收拢。
- `walk_*_1`：袍摆回到中心。
- `walk_*_2`：袍摆右侧展开 1 px，左侧收拢。
- 上半身保持稳定，避免像轻装角色一样大幅摆臂。

## 5.5 战斗 Cast 五帧

- `cast_0`：标准待机，法书靠近胸前。
- `cast_1`：抬起法书/施法手，袖口展开。
- `cast_2`：另一只手前伸，头发和袍摆开始受魔力影响。
- `cast_3`：法术核心最亮，手臂完全展开；这是释放关键帧。
- `cast_4`：亮度回落，身体仍保持施法结束姿势。

## 5.6 Hit / Dodge

- Hit：上身后仰，袍摆和袖口比身体晚 1 帧跟随。
- Dodge：侧移幅度中等，不像轻装弓手那么快，也不如重甲那么小。
- 魔法角色的动作应显得“平稳、克制”，避免夸张跳跃。

# 7. 导入验收清单

每名角色交付前必须逐项确认：

- [ ] 地图画布严格为 32×32。
- [ ] 所有地图帧脚底落在同一基准线。
- [ ] Idle 不产生上下漂浮。
- [ ] Walk 是腿与重心变化，不是整个人上下弹。
- [ ] 左右方向不是简单无脑镜像，武器/披风/箭袋位置合理。
- [ ] 战斗画布规格统一。
- [ ] 战斗脚底线一致。
- [ ] Attack/Cast 的关键接触或释放帧轮廓清楚。
- [ ] Hit、Dodge、Defeat 能只看剪影分辨状态。
- [ ] 地图、头像、战斗人物使用同一发色和服装主色。
- [ ] 不包含任何既有商业游戏直接提取或逐像素临摹的角色素材。

# 8. 游戏加载规则

当前 `CharacterAssetResolver` 已经支持本文档使用的命名方式：

- 地图：`map/<state>_<direction>_<frame>.png`
- 战斗：`battle/<state>_<frame>.png`
- 头像：`portrait.png`

帧编号从 `0` 连续递增。中间不能缺号；程序遇到第一张不存在的编号后会停止继续扫描该动画。

因此正式美术按本文档完成后，直接放入对应角色目录即可自动替换现有程序像素回退模型，不需要修改战斗数值或寻路代码。
