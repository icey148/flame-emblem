# 战斗界面正式规格

这份文档固定 Flame Emblem 当前确认的 1280×720 横向战斗界面规格。后续人物、特效、文字和正式像素素材都必须围绕这套布局工作，不再切回旧灰蓝舞台或其它 HUD 结构。

## 1. 总体构图

- 设计分辨率：1280×720。
- 背景：纯黑，不绘制地形舞台、渐变天空或装饰纹理。
- 敌军固定在左侧，我方固定在右侧。
- 战斗人物位于上半部，脚部接近左右状态框上沿。
- 左右各一个大状态框，中间只保留窄间隔。
- 中央攻击提示框悬浮在两个身份区下沿之上。
- 战斗画面不显示头像，不显示顶部 VS 栏，不显示额外的跳过按钮。

## 2. 阵营颜色

### 我方

- 主色：深蓝。
- 用于战斗人物主体服装、右侧状态框数据区、地图阵营识别和对话头像边框。

### 敌方

- 主色：粉红 / 玫红。
- 用于战斗人物主体服装、左侧状态框数据区、地图阵营识别和对话头像边框。

HP 的实际危险程度不额外改成现代渐变；战斗参考界面中的分段条以白色已填充块和阵营色深色空块为主。

## 3. 1280×720 坐标

代码中的唯一来源是 `scripts/visual/ReferenceBattleLayout.cs`。

- 左人物控件：`(210, 40)`，尺寸 `420×390`。
- 右人物控件：`(700, 40)`，尺寸 `420×390`。
- 人物 / 武器特效区域高度：`305`。
- 双状态框整体位置：`(85, 305)`。
- 双状态框整体尺寸：`1110×380`。
- 单侧状态框：`540×380`。
- 左右状态框间隔：`30`。
- 黑色身份区高度：`172`。
- 中央结果框位置：`(355, 405)`。
- 中央结果框尺寸：`570×105`。

不得在其它战斗表现类里重新复制一套不同数字。

## 4. 单侧状态框

上半部：

- 黑色背景。
- 粗白色硬边框。
- 中文角色名。
- 中文职业名。
- `LV` + 等级。

下半部：

- 整块阵营色背景。
- 四行固定信息：`HP`、`HIT`、`ATC`、`DEF`。
- 每行使用固定数量的矩形像素分段，不使用平滑 ProgressBar。
- 已填充块使用高亮白色；空块使用阵营主色的深色版本。

## 5. 中央信息框

- 纯黑背景。
- 粗白硬边。
- 白色硬边字体。
- 只显示当前战斗步骤，不长期堆叠多行信息。

示例：

- `掠夺者的攻击`
- `未命中`
- `造成 8 伤害`
- `必杀！ 造成 18 伤害`
- `获得 24 EXP`

## 6. 像素清晰度

项目必须保持以下规则：

- 根画面固定在 1280×720 viewport 中渲染。
- 窗口使用整数倍缩放。
- 画面保持 16:9；不匹配区域留黑边。
- 人物、头像、特效纹理使用最近邻过滤。
- 战斗文字关闭字体抗锯齿与次像素定位。
- 动画关键位置尽量落在整数屏幕像素。
- 不对低分辨率 PNG 使用非整数拉伸。

## 7. 战斗人物

人物视觉语言与确认参考保持统一，但角色身份细节为原创设计。

保留：

- 修长职业比例。
- 明确的职业大轮廓。
- 多层盔甲关系。
- 披风大结构。
- 面向对手的侧视战斗姿态。
- 蓄势、出手、收势的动作节奏。

原创：

- 面部。
- 发型。
- 甲片细节。
- 武器细节。
- 徽记。
- 角色个人配色分布。

正式战斗像素素材以 96×96 为首选生产尺寸；缺失时由程序人物层提供同一比例的回退表现。

## 8. 对话头像

对话界面与战斗界面不是同一布局，但必须共用像素清晰度和阵营识别规则：

- 左右头像同时保留。
- 当前说话者高亮，另一侧只轻微压暗，不能直接消失。
- 我方头像边框深蓝。
- 敌方头像边框粉红。
- 正式 portrait.png 只能整数倍率显示。
- 缺少正式头像时使用原创程序胸像回退。
