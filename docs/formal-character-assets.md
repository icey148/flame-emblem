# 正式角色像素图集

当前角色正式美术统一使用 `512×576` 透明 PNG 图集，并由 `CharacterAssetResolver` 自动切片。

## 已覆盖角色

- `adrian`：亚德里安，剑士系，我方深蓝。
- `celine`：塞琳，弓手系，我方深蓝。
- `rowan`：罗文，枪兵系，我方深蓝。
- `mira`：米拉，法术系，我方深蓝。
- `raider`：掠夺者职业通用，敌方粉红。
- `guard`：守卫职业通用，敌方粉红。
- `captain`：队长职业通用，敌方粉红。

## 图集布局

- 左上 `64×64`：正式对话头像。
- `y=64` 起：`32×32` 地图人物帧，包含四方向待机和行走。
- `x=112` 起：`96×96` 战斗人物帧，包含待机、攻击、施法、受击、闪避和倒下。

## 视觉规则

- 我方主服装统一深蓝，敌方主服装统一粉红/玫红。
- 人物比例、职业轮廓、盔甲层级、披风结构与当前战斗视觉规格统一。
- 面部、发型、武器细节、铠甲细节和徽记保持原创。
- 所有像素素材使用透明背景和硬边像素，不使用运行时图像生成。
- 游戏只读取固定离线资源；缺少正式素材时才允许程序回退人物出现。

## 资源路径

每个角色或职业的正式图集放在：

`res://assets/characters/<key>/sheet.png`

若仓库通道需要文本形式保存，也允许使用：

`res://assets/characters/<key>/sheet.b64`

`EmbeddedCharacterArtCatalog` 只负责把固定 Base64 PNG 解码成纹理，不联网、不生成图像、不参与玩法逻辑。
