# 正式战斗视觉标准 v2

本标准以 2026-08-22 用户确认通过的最新战斗设计稿为唯一人物与战斗 HUD 视觉基准。

## 核心构图

- 纯黑背景。
- 左侧敌军、右侧我方。
- 上半屏使用大比例正式人物立绘/战斗像素人物，不再使用 96×96 方块占位人。
- 下半屏左右各一组人物信息区，并在最外侧放置正式对话级头像。
- 敌方主色使用玫红/酒红，我方主色使用深蓝。
- 面板使用深色底、细金边、少量浅色分隔线，不再使用旧的纯白粗框作为最终视觉。
- 中央结果框覆盖左右信息区上沿，保持黑蓝深底与金边。

## 角色表现

- 战斗人物、对话头像、地图人物必须来自同一套角色设计。
- 塞琳的正式外观以最新确认稿为准：金发、蓝色轻装弓手、白色围巾/披肩、棕色皮革护具。
- 掠夺者以最新确认稿为准：深玫红兜帽与披风、深色面罩、双短刃/短刀轮廓、棕色皮革护具。
- 其他角色沿同一画面密度、材质层级和角色比例制作，但脸、发型、装备细节、徽记与身份保持本项目原创。

## UI 信息

每侧信息区显示：

- 中文名字
- 中文职业
- 武器
- `LV`
- `HP`
- `HIT`
- `ATC`
- `DEF`

数值仍然读取真实战斗规则结果；设计稿中的示例数字不能写死。

## 资源策略

- 正式战斗人物优先使用高细节透明 PNG。
- 正式头像使用独立 PNG，不再调用程序生成胸像。
- 正式资源缺失时宁可留空，也不再显示废弃的方块人物/程序头像。
- 所有资源离线加载，不在运行时生成美术。

## 废弃方案

以下方案不再作为正式输出：

- `ReferenceBattleFigureControl` 程序矩形人物。
- 旧 `battle_ref.png` 80×75 方块人物。
- 旧 `battle_v3.b64` 96×96 简化人物。
- 程序生成的对话胸像作为正式头像。
